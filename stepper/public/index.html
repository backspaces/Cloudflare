Stepper

AgentScript's Schelling model, living on Cloudflare in a Durable Object. There's one model, shared: anyone using this page steps the same one. Each button sends one request to the Worker; the answer is the model's data.

Setup makes a model. Leave it alone for more than about 10 seconds and Cloudflare puts its object to sleep, forgetting the model. The next button then shows it being rebuilt.
